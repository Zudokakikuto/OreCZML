// HELP FOR MODELS \\

This folder can contain all the models you want to load in the scene.

* 3D Models

The 3D models must be .glb files. Be sure the model you load renders well (use Blender to visualize it first).

* 2D Models

The 2D models can be any image format file (.png is recommended).

* Load models
You just has to create a String that will contains the path of your model, and use it in a CzmlModel.
In a spacecraft object you can use .withModelPath() and enter your String.
